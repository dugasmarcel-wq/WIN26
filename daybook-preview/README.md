# Daybook Preview
Independent experimental application based on verified Dayboox 1.13 (14) release, not a production update. Package com.marcel.daypreview; label Daybook Preview. Existing app and its update feed are not modified. The workflow downloads and inspects the released APK, retains native code and original assets, overlays the experimental interface, and verifies package, checksum and independent signing. No production signing key is needed. Production update networking is disabled. A one-off preview signer is generated in temporary storage; future in-place preview upgrades are not guaranteed.
 
Implemented in this initial overlay: front-page journal styling, four interactive progress rings, swipe time dial and manual adjustment, direct one-hour logging, start/pause/finish stopwatch (pause saves elapsed time), active stopwatch bar, full-width task check-offs, week-to-date review, notebook search. The existing release's calendar, notes, category pages, reminders, and settings remain in place.
 
Not implemented in this initial overlay: native habit weekday recurrence, recurring responsibilities/reminders, automatic backups, new widget controls, persistent paused session state, automatic generated priorities, complete category/calendar/statistics redesign. No Android device testing has been performed. Verify the APK and device interactions before reliance. Use the production app's export and preview import only if you choose to test with copied data; never restore preview data into production without validating compatibility.
